L'onglet **Rapports** d'Analytics &amp; Rapports permet de générer un
rapport d'activité ponctuel et, en complément, une analyse rédigée
assistée par intelligence artificielle.

## Générer un rapport

Choisissez la **période** (date de début et de fin, toutes deux
requises), les **modules à inclure** (tous sélectionnés par défaut) et
le **format** (PDF ou Excel), puis lancez la génération. Le rapport est
automatiquement archivé dans la Gestion Documentaire, catégorie
« Rapport », et téléchargeable depuis l'historique ci-dessous. En cas
d'échec, un message l'indique - il suffit de réessayer.

## Générer l'analyse

Une fois un rapport généré, une analyse rédigée assistée par
intelligence artificielle peut être demandée pour ce rapport - depuis le
message de confirmation qui suit la génération, ou plus tard depuis la
colonne « Analyse IA » de l'historique.

## Consulter l'analyse

Une analyse générée peut être ouverte pour consultation depuis
l'historique. Un avertissement rappelle que les faits, chiffres et
recommandations doivent être vérifiés avant toute décision. Une analyse
déjà validée ou rejetée reste également consultable, en lecture seule.

Selon vos droits, des actions de validation supplémentaires peuvent être
disponibles.

## Historique

L'historique liste tous les rapports (générés automatiquement le 1er du
mois, ou à la demande), avec leur période couverte, les modules inclus,
le format et le statut de leur analyse.
