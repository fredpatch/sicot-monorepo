SICOT (Système Intégré de Coopération Internationale et de Traduction)
centralise les demandes de traduction, les missions, la coopération
internationale et les documents de l'ANAC.

## Se repérer dans l'application

La barre latérale à gauche liste les modules accessibles à votre compte -
elle s'adapte automatiquement selon ce que votre compte est autorisé à
faire, vous ne verrez jamais un module auquel vous n'avez pas accès. Elle
peut être réduite en icônes via la flèche en bas.

L'en-tête, en haut, propose :

- le bouton **Aide** (icône point d'interrogation), qui ouvre un panneau
  d'aide contextuelle pour la page en cours ;
- le sélecteur de langue FR/EN ;
- votre profil (nom, rôle) et la déconnexion.

## Votre espace personnel

Trois écrans réunis sous « Mon espace » vous concernent directement :

- **Mon espace** - vue d'ensemble de ce qui vous concerne dans les
  différents modules ;
- **Mes demandes** - les demandes de traduction que vous avez vous-même
  soumises ;
- **Mes missions** - les missions auxquelles vous participez, avec le dépôt
  du rapport officiel quand vous en êtes responsable.

Ces écrans sont personnels : ils ne montrent que ce qui vous concerne, pas
l'ensemble des données du système. Selon votre compte, vous verrez peut-être
aussi des registres globaux (toutes les demandes, toutes les missions...) -
ce sont des écrans distincts, réservés au personnel opérationnel et à
l'administration.

## Où trouver de l'aide

- Le bouton **Aide** de l'en-tête ouvre un tiroir avec des explications
  courtes pour la page où vous vous trouvez.
- Ce tiroir renvoie, quand c'est pertinent, vers des articles plus complets
  comme celui-ci - accessibles à tout moment depuis le centre d'aide
  (« Ouvrir le centre d'aide » en bas du tiroir).
