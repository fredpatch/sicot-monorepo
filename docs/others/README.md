# `docs/others/`

Supporting source/reference artifacts - not canonical technical or user
documentation. `docs/` (this directory's parent) is the canonical,
versioned documentation; `docs/others/` holds project reference material
supplied alongside it (feasibility study, terms of reference, project
plan, a historical repository snapshot).

None of these files are a source of truth for the current implementation
- for that, see the rest of `docs/`. The `.tar.gz` in particular is a
supplied historical snapshot, kept for reference only; its contents are
not documented here and should not be treated as reflecting the current
codebase.
